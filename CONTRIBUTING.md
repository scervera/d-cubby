# Contributing

Thanks for helping improve D-cubby.

- **Bugs and ideas:** open an issue with steps to reproduce or the problem you want solved.
- **DAM behavior** (assets, tags, search, smart folders, drop zones, AI tagging) lives in the
  [`dam` gem](https://github.com/scervera/dam). Changes there belong in that repository.
- **Pull requests:** keep them focused, include tests, and make sure CI passes
  (`bundle exec rspec`, `bundle exec rubocop`, `npm run lint`, `npx tsc --noEmit`, `npm run build`).
